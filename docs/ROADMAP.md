# 功能路线图

## 已完成 (v1.0)

- [x] 火山引擎流式 ASR 接入
- [x] 16kHz 单声道音频采集
- [x] 全局快捷键（Option+Space）
- [x] 自动粘贴到当前应用
- [x] DeepSeek LLM 文本后处理
- [x] 浮动状态条（实时音量 + 状态）
- [x] 主窗口控制面板（录音 + 设置 Tab）
- [x] 菜单栏集成
- [x] API 连接测试
- [x] .app 打包 + 应用图标
- [x] 历史记录持久化（JSON 存储、搜索、CSV 导出、上限 1000 条）
- [x] 热词管理（手动增删改 + 批量编辑）
- [x] 热词 → ASR 集成（火山引擎 context.hotwords）
- [x] 热词 → LLM 集成（PromptBuilder 自定义词汇区块）
- [x] 自动学习修正（WordDiff LCS 算法 + LLM 验证）

## 计划中 (v1.1)

- [ ] **片段替换（Snippets）** — 触发词 → 替换文本规则，粘贴前执行文本替换
- [ ] **剪贴板历史** — 保留最近 N 条粘贴内容，支持回溯
- [ ] **多语言支持** — 设置中切换识别语言（中文/英文/日文等）
- [ ] **快捷键自定义增强** — 支持鼠标侧键、Fn 键等特殊键位

## 远期愿景 (v2.0)

- [ ] **LLM 模式切换** — 快速模式（不走 LLM）、智能模式（修错字）、翻译模式（中英互译）、润色模式（正式书面语）
- [ ] **投机执行** — 录音中静默 800ms 自动对 partial 文本调 LLM，停录时直接用结果，零等待
- [ ] **多 ASR Provider** — 接入 Deepgram、OpenAI Whisper API 等，用户可选
- [ ] **实时翻译** — 说话的同时翻译成目标语言并粘贴
- [ ] **语音指令** — 识别特定关键词触发操作（如"换行"、"删除"、"撤销"）
- [ ] **录音文件保存** — 可选保存原始录音，方便回听
- [ ] **快捷短语** — 预设常用语，语音触发快速输入
- [ ] **自定义 Prompt 模板** — 内置纠错/润色/翻译模板 + 用户自定义
- [ ] **App 打包签名** — Developer ID 签名 + DMG 分发 + 自动更新
- [ ] **iCloud 同步** — 设置和热词跨设备同步

## 技术债务

- [ ] SettingsView.swift 中的独立设置窗口可以移除（已被主窗口 Tab 替代）
- [ ] VolcASRClient 的 session 属性需要更安全的生命周期管理
- [ ] 浮动条需要支持多显示器定位
- [ ] 需要添加单元测试（ASR 协议编解码、WordDiff、LLM prompt 构建等）
